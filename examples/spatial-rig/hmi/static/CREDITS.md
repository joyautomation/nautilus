# Assets

`models/*.glb` are the package's built-in kinds as data (`hmi-3d/models/`,
generated by `build.py` there); copied here because the app serves
`static/` at `/`. They are small and committed.

`env/` and `textures/` are **not in git**: `../fetch-assets.mjs` fetches
them from the `spatial-assets-v1` GitHub release, verified against
`../assets.json` (`npm run assets`; also before `dev` and `build`). All
CC0, from [Poly Haven](https://polyhaven.com):

- `env/industrial_workshop_foundry_1k.hdr` — "Industrial Workshop Foundry"
  HDRI, Dimitrios Savva (photography), Jarod Guest (processing). 1k: it
  only lights the scene.
- `env/industrial_workshop_foundry_backdrop_6k.jpg` (and `_4k`) — the same
  photo, tonemapped, downscaled from Poly Haven's 8k tonemapped JPG: the
  backdrop the eye sees.
- `textures/concrete_floor_02_{diff,nor_gl,rough}_1k.jpg` — "Concrete
  Floor 02", diffuse / GL normal / roughness at 1k.
