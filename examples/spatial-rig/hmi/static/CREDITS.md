# Assets

CC0, from [Poly Haven](https://polyhaven.com):

- `env/industrial_workshop_foundry_1k.hdr` — "Industrial Workshop Foundry" HDRI, Dimitrios Savva (photography), Jarod Guest (processing). 1k, the size the design brief allows in git.
- `textures/concrete_floor_02_{diff,nor_gl,rough}_1k.jpg` — "Concrete Floor 02" texture, diffuse / GL normal / roughness at 1k.

`models/*.glb` are the package's built-in kinds as data (`hmi-3d/models/`, generated by `build.py` there); copied here because the app serves `static/` at `/`.
