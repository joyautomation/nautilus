This course teaches nautilus in short lessons, one idea each, practical
first: how to use it day to day, then why it works that way. Each lesson is
a page you can finish in ten minutes, and where it helps, a project you can
run in your browser and, later, a short video.

## Getting started

1. [What nautilus is](/learn/getting-started/what-is-nautilus/)
2. [Install the CLI and the editor](/learn/getting-started/install/)
3. [Your first controller, running](/learn/getting-started/first-controller/)
4. [Read the dashboard and the tags](/learn/getting-started/dashboard-and-tags/)
5. [When something goes wrong](/learn/getting-started/when-something-goes-wrong/)

## Interactive lessons

These run in your browser: the lesson on the left, a controller on the right,
and a **Check** button that tests your answer.

1. [First program: blink an output](/learn/interactive/b1-blink/)
2. [A motor start/stop in ladder (the seal-in)](/learn/interactive/b2-seal-in/)
3. [A timer: warn before the motor starts](/learn/interactive/b3-horn-delay/)
